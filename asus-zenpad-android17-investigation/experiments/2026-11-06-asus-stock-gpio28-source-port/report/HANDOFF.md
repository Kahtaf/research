## Binding, profile and pinctrl semantics

The P00A DTS adds only the public singular `extspkamp-gpio = <&pio 28 0>` and a new explicit boolean `asus,p00a-stock-speaker-gate` to the existing `/soc/mt_soc_codec_name@11220000` node through a root/node merge. The existing SoC DTS declares that node, its codec compatible, `pio`, the MT8163 controller compatible, gpio-controller and #gpio-cells2. No new controller label/address, GPIO28 pull, drive strength, slew rate, power mode or delay is invented.

`p00a_gate_probe` requires the P00A root compatible, the exact codec compatible, the explicit profile boolean, the singular property and exactly one three-cell specifier. It parses #gpio-cells, verifies the MT8163 GPIO-controller compatible and arguments28/0, puts the OF node reference, then resolves the global GPIO through `of_get_named_gpio_flags`. It rejects the plural `extspkamp-gpios` property even if the singular also exists, any nonzero active/open-drain/etc. flags, wrong pin/controller/cell count, invalid GPIO and every negative lookup result. It propagates -EPROBE_DEFER without truncation or unsigned conversion. There is no optional GPIO, pin24 fallback or guessed AW delay.

## Mixer and lifetime behavior

The header owns a serialized gate state and the existing codec's external-power cache. On is accepted only after a successful managed low request and a successful later codec callback. Values other than0/1 fail. Normal repeated On/Off is idempotent; successful state changes return1 and unchanged requests return0. The getter returns only cached command state after reported API success; it is not a GPIO voltage measurement.

Any output API failure latches a fault, performs one bounded low-command retry and returns the original error. If low retry succeeds, the cache records low, but the getter still returns -EIO and further On is blocked until a complete successful reprobe. If the retry also fails, the old cache is not overwritten with a fictional Off; the getter reports an error. There are no invalid/unowned GPIO calls, automatic pulse sequences or retry loops. A successful explicit Off after a fault may command low again but does not silently clear the fault latch.

Shutdown, platform removal, codec removal and managed cleanup stop the gate before release. Shutdown marks it stopping, so later On returns -ESHUTDOWN. Failure to command Off is logged and never represented as known physical Off. Release cannot guarantee an electrical state after a hardware/controller failure; it remains best effort and truthful. Managed cleanup invalidates the owner before the GPIO is freed, and later controls return -ENODEV. The codec allocation NULL check is enabled and profile-specific removal frees/reset its global codec allocation, permitting a clean platform unbind/reprobe. This preserves the driver's existing singleton architecture; a second owner is rejected.

Suspend quiesces the gate before the existing analog suspend sequence. Resume does **not** copy back an old external On cache or automatically re-enable the gate. Userspace must explicitly re-enable it after the route is qualified. Card/component removal also stops the gate; reactivation after that stop requires a full platform reprobe. These are explicit conservative lifecycle semantics, not a claim that stock physical suspend behavior has been observed. Existing test-control Off orders the external gate before internal speaker Off and no longer pre-clears a failed gate's cache. The test-control On branches excluded by MTK_SPEAKER remain unchanged. No factory/test route is qualified by this package.

`evidence/internal-functions-unchanged.json` checks byte equality for Speaker_Amp_Change/Get/Set, Apply_Speaker_Gain, class/PGA get/set, and Headset_Speaker_Amp_Change. The separate ClassAB implementation and AFE source are pinned, not edited. No gain/calibration/default value is added. AW-off naturally excludes its conditional AFE control branch; no replacement amplitude constant is invented. Both original HAL routes remain `qualified=false`, with unchanged file hash in `evidence/HAL-unchanged.json`.
