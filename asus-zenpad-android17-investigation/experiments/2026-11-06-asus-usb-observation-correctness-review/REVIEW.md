   Reproduction: `IndependentCases.test_reproduce_expired_binding_at_request_dispatch` retains the real reviewed source/hash/install/nonce checks and fake shell transport. It starts the binding at age179seconds and advances both wall and monotonic clocks by1.5seconds only in the sixth/final substituted server probe. That delay is within the actual probe's two-second cap. At the actual `os.write()` of the exact80-byte request, the final focused run recorded wall age180.92723107337952seconds and monotonic age180.92723441700218seconds. The adapter returned `OBSERVED_MATCH`; the fake child genuinely exited0; matching terminal evidence was fsynced; `accept_completion()` accepted it. See `evidence/reproductions.json`, `evidence/freshness-final.log`, and the matching fixed request in `evidence/fixture-audit-freshness.json`.

   Minimal parent fix: recheck current host epoch and both binding ages **after** the blocking checks/server probe, as the last dispatch gate; preserve the existing absolute observation deadline. Ensure the first request write applies that cheap gate after any writable-event wait as well. Keep the consumed session on refusal and send zero RSC bytes.
