# Notes: NICU sibling picture book research

Task: research NICU/preemie sibling picture books, common themes, metaphor comfort books, and metaphor vehicles for a parallel-metaphor toddler book.

## Sources gathered
- Hand to Hold sibling book list (authoritative NICU nonprofit list)
- CHOC, UAMS, Preemie Adventures, NICU Parent Network lists
- Metaphor comfort books: Invisible String, Kissing Hand, Wherever You Are, Heart & the Bottle, Ida Always, Rabbit Listened, Wish, Memory Box, Lifetimes, Tear Soup

## Key findings
- Many NICU sibling books are literal/didactic (explain wires, machines). Few use sustained parallel metaphor -> gap/opportunity.
- "Nine Ounces", "Kangaroo for Christmas", "You Were the First", "When You Were Born", "Small Miracles" not well-indexed as distinct NICU titles; treat cautiously.
- Kangaroo care recurring theme; kangaroo metaphor already heavily used -> tired for NICU.
- Metaphor-vehicle freshness assessment done for report.
